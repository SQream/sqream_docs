************************************
Appending String at End of Log Lines
************************************

.. note:: The ``endLogMessage`` flag is deprecated and has no effect. Setting it does not change the log output. The flag will be removed in a future version, so remove it from your configuration files.

The ``endLogMessage`` flag used to append a string at the end of each log line, in the old log format.

The following describes the ``endLogMessage`` flag:

* **Data type** - string
* **Default value** - ``EOM``
